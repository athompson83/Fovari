## Before implementation

The next meaningful commit should establish the product rather than add generic scaffolding. At minimum, it should define:

- the primary user and the progress problem Fovari solves;
- the core behavior that makes progress visible or worth celebrating;
- privacy, notification, and data-retention expectations;
- the smallest valuable MVP and its acceptance criteria;
- the MVP → Beta → Production delivery path;
- the technical stack only after the product constraints are known.
